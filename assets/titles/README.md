# assets/titles/ — анимированные заголовки («заголовок челленджа»)

Сюда кладётся **короткий клип-заголовок**: текст на **ЧЁРНОМ фоне**, формат
**1080×1920**, текст уже сверстан **вверху-слева** (как ты экспортируешь его из
своего редактора). Пайплайн говорящей головы накладывает его в начало ролика на
его же длительность: чёрный фон выбивается, в конце — плавное затухание.

Как использовать:

```bash
python pipelines/render_talking_head_dynamic_clean.py \
  --slug <видео> --input <исходник> --subtitles \
  --title assets/titles/title_001.mp4
```

Получится дополнительный файл `final_titled.mp4` (субтитры — внизу, заголовок —
вверху-слева). Параметры выбивания фона и затухания — в `config.yaml →
title_overlay`. Файлы в этой папке в git не хранятся (только этот README).
