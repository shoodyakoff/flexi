# 🎬 Flexi — начни здесь

Это инструкция для **человека, который не программист**. Кодить не нужно — со
всем техническим поможет агент (Claude). Главное правило:

> **Ничего не настраивай руками. Попроси агента — он всё сделает сам.**

---

## Самый короткий путь

Просто напиши агенту:

> «Установи всё, что нужно, и скажи, когда будет готово»

Агент проверит, чего не хватает, **сам скачает и поставит** программы и
библиотеки и напишет тебе, когда можно запускать. Тебе **не нужно вводить
команды в терминал**.

---

## Что вообще нужно (это поставит агент, не ты)

Чтобы Flexi работал, на компьютере должны быть три вещи:

- **ffmpeg** — программа, которая режет и склеивает видео;
- **Python** — на нём работает движок Flexi;
- **библиотеки Python** — «мозги» для распознавания речи, субтитров и монтажа.

Если чего-то нет — **агент скачает и установит сам**. Он только спросит
разрешения, когда нужно поставить системную программу. От тебя требуется одно:
сказать «ставь».

---

## Что нужно именно от тебя — положить своё медиа

Это единственное, что агент не может сделать за тебя: у него нет твоих видео,
музыки и звуков. Самый простой способ — папка **`raw/`** (входящие). Кидай туда
**что угодно, не сортируя**: видео, музыку, звуки, готовые куски. Потом скажи,
что хочешь собрать, — агент сам разложит файлы по местам и сделает видео.

Хочешь разложить сам — необязательно, но вот куда что:

| Что у тебя есть | Куда положить |
|---|---|
| 🟣 Любые видео, не знаешь куда | `raw/` — агент разложит |
| 🎵 Музыка (фон) | `assets/music/` |
| 🔊 Звуки/эффекты | `assets/sounds/` |
| 🎬 Перебивки, атмосфера (b-roll) | `assets/broll/` |
| 🛍 Видео продукта / запись экрана | `assets/broll_brand/` |
| 🗣 «Ты говоришь на камеру» | `assets/talking_head_sources/` |
| 🎯 Готовый хук (первые секунды) | `assets/hooks/` |
| 📣 Готовая концовка с призывом | `assets/ctas/` |

---

## Как попросить собрать видео

Просто словами. Например:

- «Разбери `raw` и скажи, что из этого можно собрать»
- «Собери рилс из того, что в `raw`»
- «Почисти это интервью: убери паузы и дубли, сделай вертикальным»
- «Сделай 3-strip из сегодняшних клипов»

Агент уточнит, если чего-то не хватает или непонятно, какой файл куда.

---

## Что можно собрать (5 режимов)

| Режим | Простыми словами |
|---|---|
| **Стандартный рилс** | Хук + озвучка + b-roll + субтитры + музыка. |
| **Talking-head** | Чистка живого видео: убрать паузы и дубли, цвет, вертикаль, субтитры. |
| **Ref-style** | Умный монтаж интервью в 5 форматов с перебивками продукта. |
| **Reel Matrix** | Много разных видео из сменных блоков. |
| **3-strip** | Три горизонтальных клипа в одном вертикальном кадре. |

Не нужно запоминать — просто опиши агенту, что хочешь, он подберёт режим.

---

## Озвучка голосом (по желанию)

Синтез голоса использует сервис **ElevenLabs** (платный). Если захочешь голос:
зарегистрируйся на [elevenlabs.io](https://elevenlabs.io), возьми там ключ и
**пришли его агенту** — он сам пропишет куда надо. **Без ключа всё остальное
работает** (можно озвучивать своим голосом и чистить через talking-head).

---

## Если что-то идёт не так

Просто напиши агенту, что не получается, — он разберётся. Или попроси:
**«проверь готовность»**, и он покажет, что не так и что с этим делать.

---

<details>
<summary>Для технарей: сделать всё вручную (необязательно)</summary>

```bash
# 1) системная программа (один раз)
brew install ffmpeg

# 2) окружение и библиотеки (venv на Python 3.12/3.13 — у самой новой версии
#    Python может не быть готовых ML-колёс)
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt

# 3) ключ озвучки — по желанию
cp .env.example .env        # вставь ELEVENLABS_API_KEY

# 4) проверка готовности
python3 check_setup.py      # или: make check
```

Технические доки на английском: `README.md`, `CLAUDE.md`, `docs/`,
`assets/README.md`, `raw/README.md`.
</details>
