# raw/ — ваш инбокс

Сюда **вы** кладёте файлы; агент их разбирает.

Складывайте сюда всё, что нужно для задачи, без сортировки — talking-head материал, b-roll, готовый
клип хука или CTA, музыку, SFX, иконки-оверлеи (PNG) или `VideoScript`
JSON. Потом просто скажите агенту, что нужно сделать ("собери рилс из этого", «сделай
3-strip из сегодняшних клипов», …).

Когда вы даёте задачу с медиа, агент:

1. сделает инвентаризацию этой папки (`ffprobe` по каждому клипу),
2. классифицирует каждый файл и покажет вам план,
3. **переместит** каждый файл в нужное место — `assets/broll/`, `assets/hooks/`,
   `assets/music/`, `scripts/`, … — сначала спросив, если что-то неоднозначно,
4. переиндексирует, чтобы пайплайны могли это использовать.

Поэтому всё, что **всё ещё лежит здесь = ещё не обработано**. Пустой `raw/`
означает, что всё разложено.

Полная карта назначений находится в `CLAUDE.md` → "The `raw/` inbox".

> Здесь ничего не отслеживается git, кроме этого README — `raw/` это локальный черновой
> ввод, а не источник истины. Используйте только то медиа, на которое у вас есть права.
