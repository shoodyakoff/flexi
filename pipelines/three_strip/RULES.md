# Правила монтажа 3-strip reels

Свод правил для пайплайна 3-strip (три горизонтальные полоски в 9:16).
Метки: **[H]** жёсткое правило · **[P]** параметр запроса (меняется от задачи к задаче) · **[QA]** проверяется авто-QA.

## 1. Формат и композиция
- [H] 9:16, **1080×1920, 30fps**, CFR. [QA: формат/fps]
- [H] Кадр = **3 горизонтальные полоски** ~632px + тонкие чёрные зазоры (12px). Снято горизонтально специально, чтобы влезло 3 видео.
- [H] Полоска заполняется по ширине (центр-кроп), **главное действие по центру**.
- [H] Вывод `libx264 + yuv420p` + `+faststart`. Никогда `hevc_videotoolbox`.
- [H] Источник 4K HDR (HLG) → **HDR→SDR тонмаппинг** (zscale+tonemap), иначе выцветает.

## 2. Ориентация (критично)
- [H] **Теги поворота iPhone врут** — решать по кадру глазами (RAW vs авто), не по метаданным.
- [H][QA-визуал] Все полоски **горизонтальные и не перевёрнутые**.
- [H] POV/в движении: midpoint бывает неинформативным (только асфальт) → проверять кадр с горизонтом.
- Перевёрнутые клипы перечисляются в `NEED180` конфига эпизода (только проверенные глазами).

## 3. Ритм и тайминг
- [H] Нарезка **0.5–3с**, динамично, но **не всегда жёстко** (кухня быстрее, подъём/уход/кофейня спокойнее).
- [H] **Асинхронный каскад**: средняя t=0, верх +0.5с, низ +1.0с; смена волной, не синхронно.
- [H] **Колонки выровнены**: в колонке у всех 3 полосок одинаковая длительность (каскад не уплывает).
- [P] Итог ≤30с / «полный день».

## 4. Разнообразие (правило тройки)
- [H][QA] **Никогда 3 похожих кадра одновременно** (не 3 доски / 3 сковородки / 3 ноута). Перцептивный хэш между полосками ≥10.
- [H][QA] Максимум **1 экран/ноут** в тройке.
- [H] Всегда **лицо где-то** ИЛИ следующий кадр по порядку с явными отличиями.
- [H] Колонка = 3 разные категории (действие + место/деталь + лицо/другое).

## 5. Лица / библиотека лиц
- Полезно держать «библиотеку» клипов-реакций (лица/эмоции) для переиспользования.
- Лицами разбавляем однообразие (готовка, вечер, финал).
- [P] **Частота лиц**: «часто» (в каждой кухонной/вечерней колонке) ИЛИ «редко» (последняя просьба).

## 6. Логика контента
- [H] **Демо → применение**: продукт 2–3с, затем 2с использования, подряд в одной полоске; 3 продукта = по одному на полоску (параллельно).
- [H] **Ревил/панорама** («где готовлю») = один динамичный ~3с на движении камеры.
- [H] **Длинное видео** → 2+ фрагмента (несколько моментов).
- [H] **Хронология** сохраняется (утро→…→вечер).
- [H] Из длинных вырезать **самое важное** (через анализ-раскадровку).

## 7. Интро и финал (bookend)
- [H] **Интро**: каскадное заполнение (центр → верх → низ появляются по очереди).
- [H] **Финал**: 3 постельных кадра появляются **одновременно** (верх — зеркало/ванная, низ — ноги, центр — ложусь), затем исчезает **верх → низ**, центр остаётся и держится (фиксация последнего кадра).
- [H] День открывается и закрывается кроватью.

## 8. Звук
- [H] Звук исходников убрать.
- [P] Музыка: трек / старт-офсет / громкость. Напр.: файл в `assets/music/`, старт 0:10.
- [H] Fade in/out по краям.

## 9. Процесс работы
- [H] **Ре-дифф папки каждый раз**: выкинуть удалённые клипы, вставить новые по хронологии.
- [H] **Анализ длинных клипов** (analyze.zsh): раскадровка с таймкодами → выбрать 1+ фрагментов.
- [H] Проверка ориентации каждого нового клипа глазами.
- Кэш тайлов по параметрам клипа → быстрые пересборки.

## 10. Критерии приёмки / QA (каждая генерация)
- [QA] Скрины финала → 3 полоски → авто-проверка: формат/fps/звук/длина; нет-3-одинаковых; пауза без лица; нет мёртвых полосок (кроме интро/финала).
- [QA] Аннотированный лист (🟥 дубль, 🟩 лицо) для визуала: ориентация, центровка, цвет, финал.
- [H] FAIL → правка колонки → пересборка (кэш) → пере-QA. Отдавать только при PASS.

## 11. Параметры запроса (дефолты пайплайна — заполнить)
- Длина: __ (≤30с)
- Музыка / старт / громкость: __ (трек / 0:10 / 0.7)
- Частота лиц: __ (часто / редко)
- Повторы клипов: __ (разрешены / **без повторов** ← последняя просьба)
- Формат: 3-strip (осн.) / последовательный полноэкранный

## Открытые противоречия (нужно решение для дефолта)
- «лицо часто» (п.4/5) vs «лицо редко» (последняя просьба).
- «переиспользование лиц» (библиотека) vs «без повторов» (последняя просьба).
